**VG-TTS: Visually Grounded Unified Text-to-Speech Synthesis**

VG-TTS is a unified text-to-speech framework that jointly leverages conventional Unicode text embeddings and pixel-based visual representations of rendered text. A single model is trained using Text-Only, Pixel-Only, and combined Text+Pixel conditioning through modality dropout, enabling flexible inference from different input representations.
